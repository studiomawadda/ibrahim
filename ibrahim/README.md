# Sous le même ciel

Site pour Ibrahim, de Hassana : une enveloppe, le livret animé, douze étoiles et une question.

## Mettre en ligne sur GitHub Pages

1. Crée un dépôt sur github.com (par exemple `sous-le-meme-ciel`). Choisis **Public** : GitHub Pages gratuit ne fonctionne qu'avec un dépôt public.
2. Clique sur **Add file → Upload files** et glisse **tout le contenu** du dossier : `index.html`, `README.md` et le dossier `img` complet.
3. Clique sur **Commit changes**.
4. Va dans **Settings → Pages**. Sous *Build and deployment*, choisis la source **Deploy from a branch**, la branche **main** et le dossier **/ (root)**, puis **Save**.
5. Attends une à deux minutes. Ton lien apparaît en haut de la page : `https://TON-PSEUDO.github.io/sous-le-meme-ciel/`

## Bon à savoir

- L'adresse du site est publique : toute personne qui a le lien peut l'ouvrir. Choisis un nom de dépôt discret si tu préfères.
- Pour un bel aperçu quand tu envoies le lien sur WhatsApp, remplace dans `index.html` la ligne
  `<meta property="og:image" content="img/apercu.jpg">`
  par l'adresse complète, par exemple
  `<meta property="og:image" content="https://TON-PSEUDO.github.io/sous-le-meme-ciel/img/apercu.jpg">`
- Le site est plus beau sur téléphone tenu à l'horizontale pendant le livret.
